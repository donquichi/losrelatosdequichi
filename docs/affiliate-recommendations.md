## Add, edit or remove an item

1. Obtain the original affiliate URL from Amazon's Associates tools and verify the exact product and account tag. Do not use an ordinary share link without verified tracking, invent tracking tags or shorten the link through an unrelated redirect service.
2. Edit the single JSON list: a unique `id`, `enabled`, short Spanish `title`, accurate original `description`, and `url`. Set `enabled` to false to remove an item everywhere.
3. Run `node scripts/build-recommendations.cjs`. It validates text, duplicate IDs/links, HTTPS Amazon destinations, and the known tracking tag for full Amazon.com links; short-link destinations must be checked separately. The build escapes markup and writes the sidebar and menu-link partials.
4. Run `node scripts/build-recommendations.cjs --check`. GitHub also runs this check so stale generated files cannot silently pass validation. If no items are enabled, both the sidebar and menu shortcut are omitted by the generator.
5. Validate Ghost, inspect desktop/mobile layouts, deploy the scoped files, and run `scripts/check-recommendations.cjs` against the origin. It checks active products and disclosures across the homepage and two current episodes. If disabling the feature entirely, verify that the navigation and section both disappear instead of using the active-product runtime check.

The JSON and generated theme files must both be committed. Editing this list does not automatically release it: automatic whole-theme deployment remains paused. Once a reviewed list is deployed, every episode uses it immediately. The owner can send the next original product links for the same review/build/release process instead of editing posts.

## Display and disclosures

The first release uses a text card with original Spanish copy and the original owner-provided link. The card does not claim personal testing or show copied merchant photos, stock, discounts, reviews or prices. Amazon's approved data tools are needed before adding changing product data. A clear Spanish commission disclosure and Amazon's required English Associate statement appear above the product links. Links use `rel="sponsored noopener"`, a merchant-specific action, and an accessible new-tab notice. Affiliate links remain distinct from donations and Google display ads.

The existing dark surfaces, red accents and typography are retained. The desktop widget sits below the homepage story recommendations and beneath episode metadata; on phones it follows the theme's normal stacked layout. The button has a minimum 44-pixel target. Product links are ordinary server-rendered anchors; JavaScript is unnecessary to view or follow them. Keep the sidebar curated rather than adding a long undifferentiated catalog.
